# ART PLAN
GOAL: replace all placeholder art with real free assets across 5 passes. Style: stylized low-poly, cold palette (blues, whites, grey) with a strong warm glow from fire and structures, moody at night, readable on phones. Mechanics stay untouched; this is a visual pass.

RULES (all passes)
- Sources: Creator Store free assets inserted via Studio/MCP, plus Part-built props where nothing fits. No uploads. If a suitable asset is missing, build it from Parts or MeshParts.
- Safety: on every inserted asset delete ALL Scripts, LocalScripts, ModuleScripts and any require/getfenv/HttpService/MarketplaceService/teleport code before use. No copyrighted IP characters or brands. Record every asset id, creator and source in docs/CREDITS.md.
- Data-driven: every id lives in src/shared/Assets.luau (name -> id), so swapping a model is one line. Replace Config placeholder ids too. Update docs/ART.md.
- Token efficiency: build with generator scripts and shared helpers (a rig helper, a prop placer, a VFX helper), not hundreds of single MCP calls. No more than 6 screenshots per pass, small. Reports <=8 lines.
- Budgets (in Config): triangles and part counts per asset class, particle caps, light caps, CollisionFidelity Box where possible, no needless CanCollide or Transparency overdraw. 30+ FPS on a mid-range phone is the bar. Apply tools/apply_perf.luau (streaming) in Pass 2 and re-run all client QA scenarios.
- Review aid: each pass adds a `/debug gallery <set>` command that spawns every asset of that pass in a labelled row so I can review in a minute.
- Gates: after each pass run scripts/check.sh and ALL tools/qa scenarios; fix regressions; update docs/ART_STATUS.md with what is done and the exact hand-review list; then STOP. After MCP "not reachable", stop_play then start_play before retrying.
- Use subagents in parallel inside a pass with exclusive file ownership, cheapest sufficient model.

PASS 1: HUB. Redesign the lobby as an OUTDOOR snowy mountain village plaza with a large open area for 15 players to run around. Include: a physical shop building with a ProximityPrompt that opens the shop menu; six big glowing ground pads (one per party size 1-6) with a soft pulse, a floating size label, and the 20s timer visible, in the style of 99 Nights; two large boards, one global max-days leaderboard and one local (this server) leaderboard; a personal stats area with a board showing the player's own stats and achievements; cosmetic mirror; lamp posts and warm lights, decorative fire pits, pines, rocks, snow particles, distant mountains, a clear spawn point; ambient sound hooks. Keep spawn, pad and shop logic as is; only rebuild visuals and attach them.

PASS 2: WORLD. Distinct look for each biome: snowy forest (pines, drifts, soft fog), frozen lake (ice material, cracks, shards, reeds), mountains and caves (dark rock, crystals, cave mouths), deep tundra ruins (wind-scoured ground, ruins, dead trees, harsh light). Terrain colours/materials, per-biome Lighting/Atmosphere that blends at ring borders, tree variants, rocks, ore nodes, ground cover, snow and wind particles. Update chunk variants and POI props (cabins, crashed planes, cave interiors, hot springs, hearth cabins). Apply streaming and re-run client QA.

PASS 3: CREATURES. Real models for hare, caribou, fish, wolf, polar bear, ice wraith, snow lurker, cave crawler, three mini-bosses, blizzard boss, the Stalker (tall, pale, never fully lit, unsettling), and lurker visuals (tree watcher silhouettes, ice scratcher marks, glowing eyes in caves). Procedural animation on simple rigs (idle, walk, run, attack, hurt, death) through one shared helper; players use free R15 animation ids (swing, eat, craft). Hit and death effects, footstep sounds hooks.

PASS 4: STRUCTURES, ITEMS, ICONS. Unique visuals for every structure, each with material tiers (wood, stone, reinforced) where relevant, and the placement ghost reusing them: campfire with distinct looks per upgrade tier (small flame, larger fire, bonfire, great fire with sparks and embers, matching light), workbench, forge, cooking station, storage chest that GLOWS (rarity tinted), wall, door, spike trap, tall watchtower, sleeping bag, map table. Make structure visuals data-driven so new structure types are cheap to add later. Held tools, weapons, clothing tiers (visible on the player), food, resources. Icons for every item rendered from the 3D models in ViewportFrames, so no image uploads are needed.

PASS 5: EFFECTS AND UI. VFX: damage hits, eating crumbs, health regen motes, warmth and frost cues, cooking smoke and sizzle, crafting sparkles, repair, achievement, Stalker tells, blizzard and false-night effects, fire meter polish. UI theme: frosted ice panels, consistent fonts and spacing, themed hotbar, inventory and crafting panels, HUD meters, shop menu, run summary, ping wheel, toasts, with tweened transitions and phone layouts. Follow docs/PLAYABILITY.md.

After Pass 5 the project returns to gameplay updates (new structure types, etc.); that is out of scope here.
