# Chest art
Tier: standard
Purpose: five visibly different loot chests (common weathered wood, uncommon iron-bound, rare frost-steel blue glow, epic spectral purple, legendary gold with a radiant beam). Glow, light, particles, open animation and sound hook scale with rarity; opened chests dim.
Owner files: src/server/Art/ChestArt.luau, src/shared/logic/ChestStyle.luau (pure look table), src/client/Loot/{ChestClient,ChestVisuals,ChestPrompt}.luau, tests/ChestTests.luau. Loot-only gear: LOOT_GEAR in src/shared/ItemCatalog.luau + tags in src/shared/data/Rarity.luau.
Public API: `ChestArt.build(rarity, cframe, parent): Model` (cframe = floor point under the chest, front faces -Z; tags the model Config.Loot.ChestTag, sets ChestRarity / LootOpened attributes, adds an "Open" ProximityPrompt on part "Base"); `ChestArt.setOpened(model, true)` (idempotent). LootService calls them via LootService.SetArtBuilder. `ChestStyle.get(rarity)`, `.validate`, `.Budget`. Client: `ChestClient.start()` (run mode, one require in init.client).
Data touched: Attributes ChestRarity, LootOpened; tag LootChest; remote LootOpenRequest {chest} (client prompt Triggered -> server re-validates).
Invariants: <= 8 parts per chest (ChestStyle.Budget.MaxParts); rare+ always has glow + tall beam (visible far); light/particle numbers inside Budget and Config.Perf.MaxParticleRate; only the nearest MaxEffectChests chests within EffectRadius have a live light + emitter; opened chests lose glow, beam, prompt and effects; one RenderStepped loop for all chests; all connections/instances cleaned on untag/destroy.
Exploit surface: none new. Client only displays; the open request is range-checked, rate-limited and state-checked by the server (LootService).
Playtest checklist (hand, no QA scenario this round): 1 walk up to each rarity: label colour matches, E / tap / X opens, 2 rare+ beam visible from 100+ studs, 3 only ~8 chests nearest you glow (check FPS in a structure with many chests), 4 open a chest: lid swings, burst, dims, prompt gone, 5 phone emulation: button >= 44 px and tappable, hold chests (epic 0.25 s, legendary 0.5 s) show a fill bar.
Sound hooks: Assets keys ChestOpenCommonSound / ChestOpenUncommonSound / ChestOpenRareSound / ChestOpenEpicSound / ChestOpenLegendarySound and ChestParticle (texture); absent or "" = silent / engine sparkle.
Status: in progress (headless done; Studio hand-check pending)
